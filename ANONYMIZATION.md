# Anonymous review copy: transformations and residual risk

## What this archive is

This is an independently re-audited rebuild of a previous anonymized supplementary ZIP. It is not a byte-identical public-repository mirror. The original research repository, submitted manuscript and original checkpoint files were not modified. All 19 scientific modules under `src/recursive_geodesic_composition/` and all 2,493,640 numeric leaves in the 194 retained historical JSON files were independently checked against the original source and previous archive.

The separately identified public cached replay adds execution/provenance I/O for the released anonymous inputs while preserving those scientific modules and historical records. It validates the published metadata derivatives under their own release identities, keeps the old byte guards intact and writes fresh outputs under `replays/`. Baseline reuse of original official safe tensors is disclosed rather than represented as recovery of the absent historical regenerated-safe cache. Current execution evidence is distinguished from historical audit verdicts in VALIDATION.md.


The external source mirror supplied for the audit did not pass the full anonymity/access checks, including after text-redaction updates. This reviewer archive therefore contains the source directly and intentionally does not link to that mirror. Raw identity-bearing audit excerpts, exact author-redaction terms and screenshots are kept outside this ZIP.

The earlier review copy already:

- replaced author identity, personal paths and project Git identifiers in retained text with neutral labels while preserving the failures/recoveries and scientific outputs;

`reproducibility/ANONYMIZATION_CHANGES.json` preserves the original-to-prior-anonymous file digest mapping. This review snapshot did not repeat that transformation or rewrite scientific records. Redundant prior packaging-run summaries are omitted; branch-construction changes and its new root history are recorded in an author-only publication audit outside this tree.

Historical fields such as `original_results_sha256` or `source_sha256` may consequently refer to an anonymous counterpart if they were rebound by the previous packaging step; their original identities remain in the prior transformation record. Do not infer historical byte identity from an unchanged metric. Package integrity is checked by the new package manifest and `SHA256SUMS`, not by treating old audit verdicts as newly executed ones.

## Binary handling

Every included PNG was compared to both the original repository and previous ZIP: identical dimensions and RGBA pixels, with no identifying ancillary metadata. Public mirrors that merely redact text can still serve an original PNG, PDF or checkpoint unchanged. That behavior was checked separately and is not assumed safe.

The six included `.pt` files remain immutable originals. Subsequent checkpoint publication hosts 63 exact originals plus three separately hashed warm-state derivatives, not identifying warm originals. The derivatives neutralize only a personal location prefix in initialization metadata and update required ZIP CRC fields. Static comparisons prove unchanged tensor-storage bytes, model/optimizer descriptors, numeric/opcode state and all non-identifying strings; file sizes/offsets remain unchanged. Original experiment hashes are preserved, and original-byte provenance guards still reject the derivatives. No tensor load/forward is claimed. See CHECKPOINT_ACCESS.md for the exact scope and hosted manifest mapping.

The subsequent cache release preserves all 8,032 tensor files and all corpus indexes/sidecars unchanged. Its sole identity-bearing field, an original implementation-parent Git label in the official manifest, is replaced with `anonymous-source-snapshot-01`; a separately hashed COMPLETE points to the derivative manifest. The original manifest/marker remain private. Original/new digests are explicit outside the cache root, frozen results/config/guards are untouched, and the official derivative does not satisfy original-byte guards. Fifteen exact identity-checked historical lineage records are retained separately as non-active evidence; raw remote inventories and identifying provenance are excluded. Upstream document IDs/content hashes and numeric embeddings remain linkable.

No named or anonymous PDF is included in the code ZIP; the separately submitted manuscript is the authority. The named public preprint's metadata was inspected outside this package and was not treated as an anonymous review document. The submitted manuscript was not edited or rebuilt.

## Integrity and provenance boundaries

`python supplement.py verify` checks every listed payload file by size and SHA-256. `reproducibility/PACKAGE_MANIFEST.json` excludes itself and the root `SHA256SUMS`; the latter additionally covers the manifest and excludes only itself. These are integrity containers, not digital signatures. The archive's own digest is supplied outside it to avoid circular self-hashing.

Inherited strict source-fingerprint checks can still reject historical saved runs even when an identified difference is only table layout. Omitted tensor caches and exact upstream provenance are separate prerequisites. Historical `AUDIT.json`/validation records remain historical evidence; this rebuild does not claim their full model-backed audits were rerun.

The outer ZIP uses relative safe paths, a fixed timestamp, uniform regular-file permissions, no comments/extra fields, no symlinks and no bytecode caches. Fresh-extraction format/command checks and the final pass/fail checklist are in VALIDATION.md and `reproducibility/FINAL_PACKAGE_CHECKS.json`.

## Residual risk

The paper title, methodology, distinctive results, experiment names and exact artifact identities can be linked to already-public named research by deliberate comparison/search. Necessary teacher/dataset revisions, checkpoint hashes and scientific filenames are preserved rather than destroyed. Upstream dependency maintainers, third-party citations and public service operators are not treated as this work's author identity.

This package minimizes direct and link-based disclosure; it does not promise perfect anonymity against public searching or knowledge held by a hosting platform. Public checkpoint availability does not establish missing historical training lineage, supply external caches or resolve inherited provenance guards. No complete from-scratch reproduction is claimed.
